# Ihsan

**The Note System** — a self-contained single-file web app.

Live: **https://lorit0t.github.io/Ihsan/**

Six priorities read every morning, a locker of bodies to step into, a guided
morning practice and stillness sit, and the review cadence that keeps it honest.

## Use it

Open the live link, or add it to your phone's home screen for the icon and a
full-screen launch. It also runs offline: download `index.html` and open it in
any browser. No install, no server, no dependencies — everything, including the
icons, is inlined in the one file.

## Hosting

GitHub Pages, served from `main` at the repo root. A push to `main` deploys.

The page carries `noindex, nofollow`: it is public because Pages requires it,
not because it is meant to be found.
